### 1.4 两种容易生成“假坡度”的误读

**误读一：把环境敏感点的“高差”当轨面标高。**

早期环评表3-1、表3-3的注释说明：“高差”以轨面为相对零点，描述敏感点/测点相对轨面的高低，不是连续轨道的绝对标高。不能对这些值做差分得到坡度。[S1]

**误读二：把敏感点的里程范围当站台范围，再取中点当车站中心。**

例如表3-3在“远东大道站”下列出西张家宅的`AK22+180～AK22+340`。这是敏感点与线路的相对位置，不能把区间中点命名为远东大道站中心。[S1]

**平面站距、运营里程、宣传全长、GIS折线长度，也都不能自动替代工程里程。** 这是数据匹配约束，不应通过“看起来差不多”放宽。

### 1.7 坡度表的导入规则

以“徐泾东 → 浦东国际机场”为本项目自定义正方向。沿这个方向轨面升高记正坡，降低记负坡；这不等于擅自指定运营方的“上行/下行”。

合格记录至少需要：

```text
source_id, source_revision, chainage_system, track_id,
start_chainage_m, end_chainage_m, grade_permille,
grade_reference_direction, evidence_location
```

车站记录至少需要：

```text
station_id, original_station_name, source_id, source_revision,
chainage_system, track_id, reference_point_type, center_chainage_m
```

只有`source_revision`、`chainage_system`、`track_id`和参考点定义能匹配，或者有明确的断链/转换表，才能叠加两种数据。不同建设阶段的资料不能只根据同名站强行拼接。

**缺竖曲线可以采用折线坡近似；缺坡度本身不能靠“折线坡处理”补出来。** 缺平曲线则单独关闭曲线阻力项，并记录这一简化。

### 2.4 AW质量不能从载客量或轴重上限硬补

这是建模数据要求，不是本线已发现的数据：

```text
M_AW2 = M_AW0 + N_AW2 × m_person
M_AW3 = M_AW0 + N_AW3 × m_person
```

只有车型的整备质量、各载荷等级对应人数、每人质量及人员计入范围全部有依据时，才能计算。不能拿另一车型载客量、普通新闻中的“最大载客”或规范轴重上限，拼成看似精确的AW2/AW3质量。

### 3.2 能确认的内容

### 3.3 本次没有可靠提取的内容

```text
specific_vehicle_model = null
maximum_tractive_effort_kN = null
constant_torque_end_speed_kmh = null

```

原因是当前可读图件刻度较模糊，不能可靠形成可复算的数据点。**没有按图形外观猜“约多少kN”，也没有把疑似转折点写成精确速度。**

后续数字化应同时保留原图页码、坐标轴单位、图像读数误差和载荷条件。不同载荷的曲线必须分别录入，不能只读取一张再按质量比例复制。

### 3.4 另一个可以引用、但不能混淆的量

专利的运行等级一至三采用`1 m/s²`加速命令，运行等级四采用`0.75 m/s²`加速命令。[S6]

这是该实施例的**控制命令设定**，不是各车型0～40 km/h实测平均加速度，更不是最大轮周牵引力；`0.75 m/s²`也不是冲击率`0.75 m/s³`。

### 4.3 用于仿真时的三个限制

**第一，平均性能下限不等于车辆参数定值。**

采用恒定加速度`1.0 m/s²`、恒定常用减速度`1.0 m/s²`和恒定紧急减速度`1.2 m/s²`，可以构造一个简化校准模型，但这个模型是研究假设，不是规范提供了一条恒值牵引或制动曲线。

**第二，新标准不能倒推出旧车的采购保证值。**

即使某型号当前仍在运行，也不能把2025版条文自动写入其早年技术协议。旧车的验收依据、扩编后的配置和后续改造版本须单独查证。

**第三，车辆性能与ATP安全模型分开。**

## 6. 参数导入时需要保留的单位与定义

本节是数学与数据结构约定，不是新发现的2号线实测参数。

### 6.1 Davis阻力

用户指定形式：

```text
R(v) = A + Bv + Cv²
```

如果`R`为整列阻力`N`，`v`为`m/s`：

```text
A: N
B: N·s/m
C: N·s²/m²
```

如果来源使用速度`V`，单位`km/h`，并写作`R = A_kmh + B_kmh·V + C_kmh·V²`，换成`m/s`输入时：

```text
A_ms = A_kmh
B_ms = 3.6 × B_kmh
C_ms = 12.96 × C_kmh
```

前提是两式的`R`单位及整列/单位质量口径一致。`N`、`kN`、`N/t`、`N/kN`不可混用。特别是`N/kN`属于单位重量阻力，需要乘以列车重力的kN数才能得到总阻力N。

**本次没有找到本线地面或隧道的A、B、C。** 不能把全列系数按车厢数再次相乘，也不能未经来源说明就假设只有隧道的C项变化。

### 6.2 回转质量系数

本报告建议统一采用：

```text
m_effective = m × (1 + δ)
```

`δ`为无量纲附加回转质量系数。其他资料可能用`1+δ`本身作为“回转质量系数”，两者不能混用。

用户给出的`0.06～0.10`可以作为假设敏感性分析区间，但**不是本次检索到的2号线参数**。不应未经其他证据就挑中值写成某车型精确值。

### 6.3 坡道阻力与方向

小坡度近似下，沿行驶方向上坡为正，坡道阻力为：

```text
R_grade ≈ m × g × grade_permille / 1000
```

`m`是实际质量，不是加入回转质量后的等效惯性质量。反向运行同一坡段时，坡度符号相反；不同正线实际纵断面不一致时，应分别建模，不能只做符号反转就当另一条线。

### 6.4 加速度、冲击率、制动延时分开

```text
acceleration: m/s²
jerk = da/dt: m/s³
traction_cutoff_time: s
brake_build_up_time_to_90_percent: s
```

不能由一条冲击率限制直接“查出”实际制动建立时间。若采用线性斜坡、固定延时等简化，应把它标为H级模型选择，并说明90%是相对目标制动力、稳态制动力还是峰值制动力。

> 所有未知量继续保留`null`；确需运行仿真时使用单独H级假设，并在输出中保留假设标记。

**结论：这份文件交付的是已取得资料、可复核出处和明确的数据缺口，不是已经补齐的工程数据库。下一项最有价值的材料仍然是“同一版正线纵断面 + 车站中心里程表 + 断链说明”。**
