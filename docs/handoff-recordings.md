## 任务 A：测量（最重要，给运行时分重新标定用）

背景：官方首末班表（`src/data/firstlast.ts`）显示全线每个区间都比模型慢，末班车全程 94/95 min，模型 76.5 min，×1.23，平均每站约多 36 s。需要知道这 36 s 里多少是停站、多少是区间运行。

从**车内录音**逐站测出，并写入新文件 `src/data/ridelog.ts`（参照 `src/data/vvvf.ts` 的头注释写清来源、方法、精度和【假设】）：

| 字段 | 判定 |
|---|---|
| `stop` | 车停稳（走行声/VVVF 制动音消失，轮轨声停） |
| `open` | 开门提示音起 |
| `close` | 关门提示音起 |
| `start` | 起车（VVVF 牵引音起） |

- 时间用「录音内秒数」，另给录音起点的钟面时刻（若用户能提供），精度 ±1 s 即可。
- 每条记录带车站名（与 `src/data/line2.ts` 的 `STATIONS[].name` 一致）、方向（`DN` 往机场 / `UP` 往蟠祥路）。
- 由此得到每站停站时间（stop→start，以及 open→close）和每个区间的站间运行时间（start→下一站 stop）。在文件末尾或 `docs/recordings.md` 里列一张表，与 `src/data/firstlast.ts` 末班车列的区间时间并排对比（末班车列是同一列车，相邻两站相减即区间+停站，分钟取整，有 ±1 min 的截断误差）。
- 判定不确定的条目标出来，不要猜。

**露天段**：往西经过张江高科—龙阳路之间的一小段露天（隧道口出入时声音明显变化：风压、混响消失/出现）。记下出隧道、进隧道的录音时刻，以及该区间的 start/stop 时刻；换算成里程由 Claude 用仿真的运行曲线做（`EXPOSED` 在 `src/data/line2.ts`，现在只有广兰路以东高架和机场地面段）。

## 任务 B：切片（本地资源，不入库）

写一个可复现的切片脚本（参照 `scripts/vvvf-clips.sh`：输入原始录音路径，ffmpeg 按时间范围切到 `public/sounds/...`，单声道，ogg/opus 或 mp3 ~96–128k）。时间范围写在脚本或数据文件里，这样换了录音只要改数字。

要切的：

1. **站台进站**（arrive）：从能听见来车到停稳后约 2 s。元数据：片段内「停稳」的时刻 `stopAt`。
2. **站台出站**（depart）：从起车前约 1 s 到声音基本消失。元数据：片段内「起车」时刻 `startAt`。
3. **站台底噪**（ambience）：没有进出车、没有可辨认人声的段落，≥10 s，可循环（首尾交叉淡化）。
4. **站台广播**：进站广播拆成「前缀」（乘客们，列车马上就要进站了。本次列车终点站）+「站名」（录到哪个就切哪个）+「后缀」（请乘客们先下后上……）；以及关门提示（车门灯闪烁……）。元数据：进站广播相对列车停稳的提前量（从录音里量：广播开始 → 本侧列车停稳）。
5. **车内报站**（若录到）：到站/下一站广播，同样拆模板与站名，供以后车内视角用；本轮不写车内播放逻辑。

两侧叠加的处理：优先选两侧错开的片段；分不开的整段保留并标记 `both: true`（仿真里两侧同时有车时用）。区分哪一侧：进站广播报的终点站、用户站位近侧声音更大更「干」。

在 `src/data/soundbank.ts` 里登记所有片段（文件名、类型、车站、方向/侧、`stopAt`/`startAt`/提前量、`both`），这是入库的元数据；音频文件本身缺失时一切保持静音（与 `src/ui/vvvf.ts` 相同：`fetch` 失败即静默）。

## 任务 C：车站音效逻辑

新文件 `src/ui/stationaudio.ts`，由 `src/ui/audio.ts` 持有（参照 `VvvfSound` 的接入方式），在 `src/ui/side.ts` 更新音频的地方（`setTraction` 附近）每帧喂数据。

行为：

- **何时响**：当前选中的是一个车站（`store.selection.kind === 'station'`）且未静音、仿真未暂停、倍速不高于 `VVVF_MAX_RATE`。新增设置项「车站音效」（照 `traction` 的 `loadPref/savePref` 做，默认开），放在设置里「走行音」旁边。
- **进站**：本站某侧有列车将在该站台停车。按列车当前速度和到停车点的距离预测停稳时刻（常用制动减速度 `PERF.bService`），在 `停稳时刻 − stopAt` 开始播放 arrive 片段，让片段里的「停稳」对上仿真的停稳。只对 ATO/AM 正常进站播放；人工驾驶、RM、通过不停车的列车不播（节奏对不上）。预测误差超过 ~1.5 s 时宁可不播。
- **出站**：该侧列车关门后起车的瞬间（`phase`/`v` 由 0 变正）对齐 depart 片段的 `startAt`。
- **广播**：该侧第一班列车预计停稳前「提前量」秒播放 前缀+站名+后缀；终点站名没有录到的，不播这一句（不要用别的站名代替）。关门提示在该侧 `doors` 由开到关时播放（站台上能听到的那一份；车内的门铃仍是 `doorChime`）。
- **底噪**：选中车站期间循环播放，音量低。
- 两侧独立；两侧同时有事件且有 `both` 片段时可用之。
- 不改 `pisview.ts` / PIS 的样式（Claude 同时在改 PIS 显示）。需要第一班列车信息就读现有的 PIS 数据（`PisData`），只读。

把可测的部分写成纯函数（例如：由列车状态与片段元数据算出开始播放的仿真时刻/是否播放），并写 `tests/stationaudio.test.ts` 单元测试。另外写 `scripts/mock-soundbank.mjs`：按 `soundbank.ts` 生成同名的占位音频（短促的不同频率提示音即可），这样没有录音的环境（云端、CI、别人的克隆）也能验证调度。
