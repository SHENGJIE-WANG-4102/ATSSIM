# 交接说明：站台 PIS 还原度（给 Codex）

依据是用户 2026-10-14 晚在江苏路、金科路、世纪大道拍的站台 PIS 照片（读数见 `docs/handoff-claude-local.md` 的「实地数据」）。分工和 `docs/handoff-recordings.md` 一样：**Codex 只改工作区，不 commit、不 push、不切分支**；做完告诉用户，由 Claude 审完提交。不要在代码、文档里写模型名称。

## 涉及文件

- `src/ui/pisview.ts`：版面和动画（中间框第二/三班轮换 20 s，底部框时钟/站名轮换 3 s，`slide()` 左右推）。
- `src/sim/pis.ts`：`computePis()`，每站的 PIS 数据。
- `src/styles.css`：`.pis2` 一族样式（约 294 行起）。
- `src/data/firstlast.ts`：官方首末班表 `FIRST_LAST`（`firstE/firstW/lastE/lastW/lastG`，过午夜写成 24:xx）。
- `src/data/line2.ts`：`STATION_EN`。

## 要改的（按优先级）

1. **首末班页**：中间框改成「第二班 → 第三班 → 首末班」三页轮换，每页的时长保持现有节奏。首末班页显示**第一班列车目的地方向**的首班 / 末班时刻（实拍：江苏路往东时显示「往机场 05:52 / 22:24」，同时还有「往广兰路 05:52 / 23:09」）。数据取 `FIRST_LAST`，按站名匹配。目的地是机场 → `firstE/lastE`；广兰路 → `firstE/lastG`；蟠祥路 → `firstW/lastW`；其他终点（比如载客回段的龙阳路、淞虹路）→ 用该方向的大交路列，并在代码里注明这是【假设】。24:xx 显示成 00:xx。首末班数字是淡紫色。
2. **倒计时超过 60 min**：现在 `countdown()` 在 ≥6000 s 时显示 `--:--`，60–100 min 之间显示成 `73:12`。改成 >3600 s 就显示文字「预计大于1小时」（实拍原文），没有车仍是 `--:--`。在站显示 00:00 不变。
3. **蟠祥路英文名**：`STATION_EN` 的 `PXL` 改为 `Panxiang Rd. • SNAI`。全仓 grep 一下，看还有没有别处硬编码了旧英文名（tooltip、help、测试）。
4. **英文目的地放不下时横向滚动**：从右侧滚入，循环滚动，不要用省略号，放得下就静止。中文目的地不变。
5. **底部框切换动画**：时钟 ↔ 站名改成上下滚动 + 淡入淡出，不再左右滑。中间框的列车切换保持现在的左右推。
6. **七段数码管字形**：倒计时、首末班时刻、时钟都用带倒角的七段字形，颜色浅天蓝（首末班用淡紫），不要发光。推荐打包 DSEG7 Classic（SIL OFL 1.1）：woff2 放 `public/fonts/`（或 `src/ui/assets/`，看 Vite 哪种更顺），**OFL 许可证全文一起放进去**，在 README 的第三方资源处注明。字体加载失败时回退到现在的字体，版面不能塌。
7. （可选，最后做）左侧主画面做成轮播：站点条 ↔ 宣传卡（纯文字/色块即可，不要用任何真实宣传片素材或申通的图）。不确定就跳过，告诉用户。
