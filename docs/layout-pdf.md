## 逐站对照

“当前 `LAYOUT`”一栏对应 `src/data/line2.ts` 的 `LAYOUT`。名词：**双Y＋菱形**（`pairs`）是两条尽头线夹在两正线之间，站台端各正线先接一组道岔，再分岔到两条尽头线，两条交叉腿过菱形，故任一正线可进任一尽头线，上行→上侧线与下行→下侧线可同时进路，兼具渡线作用；`at` 为道岔组到站中心的距离（m，负为站西），正线上的道岔再往回40 m。**中间线**（`loops`）两端各一Y接两正线。**出入段线**（`lead`）是尽头线伸入车辆段，`flow` 为 in/out 即单向。

## 对折返的影响

小交路仍是淞虹路—广兰路（`timetable.ts` SHR=4、GLL=22），大交路两端是蟠祥路和浦东1号2号航站楼。各站折返方式（`turnbackAt`先看后折返线，再看站前折返）：

**后折返**（进尽头线／尾轨／中间线站台换端，列车朝线路端部方向进线，所以站西的线供上行到达的车，站东的线供下行到达的车）：

- 蟠祥路（上行到达）：进`PXL1/2`两条折返线（各420 m，模型值，可容连挂救援的两列编组），最短折返240 s；两正线尾轨只存车。
- 浦东1号2号航站楼（下行到达）：东侧尾轨＋剪刀，最短折返240 s。
- 淞虹路（上行到达）：进`SHR1/2`，也就是北翟路的两条出入段线，容量2，最短折返240 s。出入段车接近淞虹路时会预留它要走的那条线，折返车改用另一条。
- 广兰路（下行到达）：中间线站台折返，不进上行正线站台，和上行大交路车在同一岛式站台两侧同时停靠，没有敌对进路；能力1列（`TERMINAL_CAP[22]=1`），最短折返100 s。
- 其余设有折返线的站，模型可以折返但运行图目前不用：国家会展中心（上行到达，`GJH1/2`）、海天三路（上行到达，`HTS`）、上海科技馆（下行到达，`KJG1/2`）、龙阳路（下行到达，`LYL`）、远东大道（下行到达，`YDD1`）。
- 威宁路`WNL`、人民广场`RMG`和蟠祥路两正线尾轨只存车（`turnback:false`），不作折返。

**站前折返**（经站台一端的渡线在站前换到对向站台，原地换端；由渡线所在侧决定哪个方向可用）：

- 虹桥火车站：无渡线，不能折返；虹桥枢纽加开车延至国家会展中心折返，定点班车由回北翟路的空车在虹桥火车站上线。
- 威宁路（东侧渡线，上行到达）、中山公园（东侧剪刀，上行到达）、人民广场（西侧渡线，下行到达）、凌空路（西侧渡线，下行到达）：几何上可站前折返，实际是否可用以`topology.ts`的`frontTurnback`判定为准。
- 上海科技馆已无独立渡线，只能后折返；世纪大道渡线已删。

**车辆段接轨点与换端**：`topology.ts`按接轨点和出入段线实际可达性，为每个车辆段分别判定四个门户（出段下行／上行、入段下行／上行）是否`reverse`。出入段线接在站西（淞虹路）或站东（龙阳路、远东大道）时，一个方向可以直接进正线站台，另一个方向要先到站台反向停靠、换端后才上正线：

- 出段：先在接轨站对向站台反向停靠，注明“出段换端”，换端（最短40 s），再回到本方向站台待发；出段运行时间另加`PORTAL_REVERSE`=90 s（`timetable.ts`的`portalExitTasks`处理停靠与换端，`PORTAL_REVERSE`用于出段走行时间）。
- 入段：先在接轨站站台停靠，注明“回段换端”，换端（最短40 s）后入段（`depotTasks`）。
- 按当前几何：淞虹路（线在站西）上行出段、下行入段要换端；龙阳路、远东大道（线在站东）下行出段、上行入段要换端。其余方向直接进出。
- 淞虹路：下行出段、下行回段换端走`SHR2`直股，上行出段、上行回段走`SHR1`直股，两股互不交叉。
- 换端后的逆向走行由ATS整段预留：回段车接近换端站台时即保护其换端后的逆向径路，后续同向列车在径路外的信号机前等待；出段换端车先进出入段线在线端信号机待令，整条逆向进路可一次排通时才出发。
- 运行图：同一门户连续的换端出段车，在换端站台的发车间隔不小于150 s（`PORTAL_CYCLE`），优先利用远端折返的富余时间往后移。
- 线路两端（蟠祥路、浦东1号2号航站楼）到达的车都在此折返、不通过，所以折返能力（`TERMINAL_CAP`，即折返线＋发车站台）之外还可让一列在到达站台等候，条件是下一列到达时，等候车已经有空位并已腾出站台（空出后至少120 s，`HOLD_CLEAR`）。中间站（如淞虹路）的到达站台还要供通过车用，不放宽。
- 蟠祥路下行尾轨除折返位外，靠站台一侧再划一个存车位（`storageBerths`，`…下行尾轨(内)`），出口信号直通下行站台。早高峰06:20–06:45出段车挤在淞虹路出口、蟠祥路折返不够用时，编图（`stableInstead`）把首趟是出段空驶的车次改成前一晚就停在尾轨（夜间正线存车，属于计划内的存车方式），占用不超过夜间存车数＋存车位数。运营中不在正线上临时停放列车。
- 连挂救援的两列编组（约373 m）回段时，若入段要在接轨站站台换端，换端后整列须在出入段线道岔以内（站台停车标到接轨点≥编组长＋60 m）：龙阳路可以，远东大道上行、淞虹路下行不行，故改去能容下的车辆段。
- 淞虹路出段线的尽头线兼作折返线：小交路车折返时，若出段车会在它再次发车前经过同一尽头线出段，就改用另一条折返线。

## 已应用

上表“结论”一栏已落到 `src/data/line2.ts` 的 `LAYOUT`（tails / pairs / sidings / loops / crossovers / depots）与 `src/sim/topology.ts`：

- 双Y＋菱形（`pairs`）：蟠祥路（−205 m，2×420 m）、国家会展中心（−205 m，2×400 m）、淞虹路（−205 m，2×260 m出入段线）、上海科技馆（+205 m，2×350 m）。
- 蟠祥路尾轨无剪刀、仅存车；浦东1号2号航站楼尾轨＋剪刀可折返。
- 尽头线／存车线（`sidings`）：威宁路（上行侧）、人民广场（下行侧）为沿站台存车线；龙阳路折返线＋连接线＋入段线、出段线；远东大道出入段线＋出段线；海天三路新增尽头线。
- 中间线（`loops`）：广兰路（站台折返，100 s）、创新中路（不折返）。
- 渡线：威宁路+215 m；中山公园+175/+295 m剪刀；人民广场−215 m；凌空路−215 m。虹桥火车站、唐镇、川沙、世纪大道、远东大道（站西）、中山公园（站西）、龙阳路（站西）的旧配线已删除。
- 车辆段（`depots`）容量36/24/32，接轨点分别为淞虹路站西、龙阳路站东、远东大道站东；配属100列。

仍为假设：

- 虹桥火车站、世纪大道两站 PDF 未画渡线，均已删除；虹桥方向的加开在国家会展中心折返。
- 龙阳路、远东大道的下行正线接入用连接线／中间线经Y近似。
- 广兰路中间线两端的短安全线、东端剪刀（上行↔中间线）与中间线→下行的东端连接简化为 Y 形道岔接两正线。
- 长度：PDF 不按比例，尽头线／尾轨长度为模型值（折返线取260–400 m，国家会展中心、海天三路PDF约300 m）。
