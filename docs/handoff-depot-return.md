## 第 1 段：车辆段收支闭合，车载客开回自己的段

**通用规则**：每列车有一个夜间归属，也就是它当晚要回的车辆段或正线存车位。它退出运营前的最后一趟载客车次，终点设在它回去的那个地方：
- 回北翟路：往西开，到淞虹路终到；
- 回龙阳路：往东开，到龙阳路终到，直接进段；
- 回川沙：往东开，到远东大道终到，直接进段。

不再先开到端站、再空车回头。

**夜间归属的分配**：
- 每个车辆段夜里不超过库位；
- 一天结束时每个车辆段的车数，等于第二天早上出段需要的数量。

在这两条前提下，分配让空驶和换端最少。

这条规则要能自然排出第 3 节里实拍看到的混排：往东的车里夹着龙阳路、远东大道终到的，往西的车里夹着淞虹路终到的。现有的 `lateReturns`（22:30 起龙阳路隔列终到）、`lateOrigins` 如果被这条通用规则覆盖了，就删掉，不要两套并存。删不掉的说明理由。

**校验新增两条**：
- 夜里某个车辆段的库存超过库位，报错；
- 一天结束时各段车数和早上需要的不一致，报错。

两种日型都要过。这两条要写测试：人为把一列车改回别的段，必须报错。

**完成标准**：
- `npx tsx scripts/validate-plan.ts weekday` 和 `weekend` 都是 0 error，新的两条校验通过；
- 机场到远东大道的空车回段，工作日、双休日都是 0 列（机场尾轨过夜车的进位除外）；
- `npx tsx scripts/firstlast.ts` 和改前一致，或者末班偏差不超过 ±60 s；
- `npx tsx scripts/gaode-compare.ts` 不合格格数不超过现在的 11 格，可信列不能变差；
- 用车 `fleetPeak` 不超过 86；
- 整个模拟器初始化不慢于 2.5 s，现在约 2.1 s。
