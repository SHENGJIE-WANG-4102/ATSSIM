## 任务 A：读数表和列序（先做，做完停下来汇报）

   | 字段 | 说明 |

   | 时刻 | 屏幕时钟优先，没有就用文件名时间，标注是哪一种 |
   | 车站、方向 | 从站台站名牌（「下一站／上一站」）、屏底站名判断，写明依据 |
   | 位置 | 第一班、第二班、第三班或首末班页 |
   | 终点 | 中文和英文都记 |
   | 倒计时 | 照原样记 |
   | 置信度 | 高、中、低 |

   看不清的写「看不清」，不要猜。车站实在认不出，就列出候选站和理由，最后只挑最少的几张让用户确认。
