## 原则

排图不应该有特例。合理的结构只有两部分：

- **时段表**：每个日型、每个方向一张，写时间段、交路、间隔、停站系数、运行等级；
- **一套通用编图规则**：对所有日型都一样。

排不出来的时候，去改通用规则或者改时段表，不要先排完再打补丁。

## 要删、要改的

1. **方向不同的时段**（往东、往西进出高峰的时刻不一样）：写进 `dayPeriods` 的数据里，比如每段带 `dir` 或各方向的起止时刻。`streamAt` 里按方向、按钟点返回的分支全部删掉。
2. **停站系数和运行等级**：从模板 / 时段里拆成单独的表，按时刻查。
   - 现在 `dwellFactorAt` 里有个检测 `weekdayAMTail` 再抄旧钟点的补丁，删掉；
   - `plannedRunLevel` 里写死的工作日 21:10 / 21:25 / 21:40，删掉；
   - 它们原有的标定值（D73、D74）保持不变。
3. **删掉 `generatePlan` 里的「校验 → 修补」重试循环**，包括砍车次、挪 ±1–15 s、改终点、改从国家会展中心始发。它现在解决的每一类冲突，都要找到原因，改成编图规则本身就不会排出来：
   - 终点站同时待发车太多（`TERMINAL_FULL`）；
   - 正线追踪间隔不够（`HEADWAY`）；
   - 折返间隔不够（`TURN_HEADWAY`）；
   - 回段与出段 / 折返冲突（`DEPOT_CONFLICT`）。
4. **魔数补车改成规则**：龙阳路开班补车的 225 / 450 / 150 s 间隔、17:07–17:20 单独加的一列、夜间龙阳路「隔一列 / 隔四列」终到。要么表达成时段表里的交路，比如「这段时间往西有龙阳路始发」「这段时间往东隔一列到龙阳路终到」，要么用通用规则生成。
5. **通用规则不分日型**。下面这些对双休日一样成立，去掉 weekday 判断：
   - `reuseTerminalReturns`；
   - `fitOpeningFeeders` 的工作日分支；
   - `relieveTerminals` 的工作日分支；
   - `blockTasks` 里淞虹路 SHR2 的分配；
   - 校验器里的 `DEPOT_CONFLICT`。

   双休日图因此有变化可以接受，但要列出变了什么。
6. **代码风格跟周围一致**：空格、换行、命名，不要压成一行。
